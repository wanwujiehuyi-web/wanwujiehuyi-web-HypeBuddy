# 查一家公司的底细

**用户这次说的是：** $ARGUMENTS

**常见场景**：考虑去上班、要不要合作、这东西值不值得买。

## 第一步：先确认是哪家

公司重名很常见（"长江""华信"这种一抓一把），先问一句：

> "你说的是哪一家？有没有官网或者全称？"

**但用户给的信息够明确就直接查，别多问。**

## 第二步：分三路搜

```
web_search[公司名]                    ← 看它自己说啥子
web_search[公司名 评价 口碑]           ← 看别人啷个说
web_search[公司名 争议 处罚 诉讼]      ← 这一搜最关键，别省
```

**前两个是"它想让你看到的"，第三个才是"它不想让你看到的"。**

## 第三步：按这个结构整理

```
【公司名】这个，我给你查了一哈——

## 是干啥子的
主营业务，一句话说清楚

## 家底
成立时间 / 规模 / 融资或上市情况 / 主要产品

## 外头的说法
口碑咋样，有没有不同的声音

## 要注意的地方
争议、处罚、负面 —— 查到啥子说啥子，没查到就明说"没查到"
```

## 完成条件

- **三条主线都查了**（自家说法 / 外界口碑 / 负面）
- 说清楚了它**靠啥子赚钱**
- 负面那一段**就算没查到也要明确说"没查到负面"** —— 不能省这一段

## 底线

- 【最重要】负面信息**必须来自搜索结果**，一个字都不许推测
- 找不到就说找不到，**别为了显得专业去编**
- **别下"这公司值得去/不值得去"的结论** ——
  你只负责把查到的摆清楚，**决定让用户自己做**
