# 每日 AI 新闻

**用户这次说的是：** $ARGUMENTS

给用户播报 AI 圈的新闻。

**注意是"播报"，不是"念搜索结果"。** 用户要的是你消化完了讲给他听。

## 第一步：搜

调 `web_search`，关键词带点时间限定：
```
web_search[AI 最新消息]
web_search[大模型 发布 2026]
```

## 第二步：挑

从结果里挑 **3~5 条**真正有分量的。挑的标准：

- 大厂 / 大模型的动作（发布、开源、融资、人事变动）
- **有具体数字的**（多少参数、多少钱、什么时间）
- 影响普通人的（涨价、免费、下架）

**宁可只讲三条，也别拿边角料充数。**

## 第三步：要不要深挖

某条特别重要、搜索结果里又说得不清不楚 → 可以 `read_page` 打开原文看看。

**最多读一篇，别陷进去。**

## 第四步：播报

```
今天 AI 圈这几件事，我给你摆一哈——

1.【一句话标题】
  两三句讲清楚是啥子事，带上关键数字

2. ……
```

最后加一句你自己的看法，或者问一句用户想细看哪条。

## 完成条件

- 播报了 3~5 条，**每条都有具体信息**（不是"某公司发布了新产品"这种空话）
- **至少有一个数字**（参数、金额、时间）
- 全程是你自己的口吻，不是复制粘贴

## 底线

- **只讲搜到的**。搜索结果里没有的，一个字都不许编
- 啥子都没搜到就直说"今天没搜到啥子新鲜事"，**别硬凑**
